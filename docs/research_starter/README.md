# SE4457 Research Starter Pack (Windows)

This pack contains **specifications and an XML-derived network audit**, not completed vehicle telemetry. The user's local 300-vehicle `routes/london.rou.xml` and installed SUMO are required to execute the real simulator.

1. Copy `driver_profiles.yaml` into your Windows repository's `config/driver_profiles.yaml`.
2. Copy `network_audit.md` and `network_audit.json` to `docs/` or keep with research notes.
3. In your VS Code PowerShell terminal in `C:\Users\suman\MAS-Insurance_data_pipeline`, activate your `.venv` and run `codex`.
4. Open `CODEX_IMPLEMENTATION.md` in VS Code and paste its content into Codex. Ask it to inspect the repository and implement phases in order, verifying locally.
5. Do not treat any prefilled parameter ranges as empirical estimates; have your PhD collaborator review and revise them.

The road speed-limit audit must be reviewed before real-world speeding claims can be made.
